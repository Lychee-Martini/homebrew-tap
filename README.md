# Lychee-Martini Homebrew Tap

Official Homebrew tap for **Lychee-Martini** command-line tools and packages.

## Quick Install

Install `martini` directly with a single command:

```bash
brew install Lychee-Martini/tap/martini
```

## Step-by-Step Installation

Alternatively, add this tap first and then install the formula:

```bash
# 1. Add the tap
brew tap Lychee-Martini/tap

# 2. Install martini
brew install martini
```

## Updating

To upgrade `martini` to the latest release:

```bash
brew update
brew upgrade martini
```

## Uninstalling

To remove `martini` and untap this repository:

```bash
brew uninstall martini
brew untap Lychee-Martini/tap
```
